# stock-calculator
Application Name: Stock Calculator
Version: 1.0.0
Author: Adi Surya Teja
Description: A web application to calculate stock prices and manage portfolios.

Application Setup Instructions:
1. Clone the repository: `git clone https://github.com/adissiva/stock-calculator.git`
2. Navigate to the project directory: `cd stock-calculator`
3. Install dependencies: `npm install`
4. Start the development server: `npm start`


Commit Message Format:
git push -m -n "Stock-Way TEAM-001 Story SWUS-001: Story message details" (format)
Stock-Way is the path of the project
TEAM-001 is the team name
SWUS-001 is the story number
Story message details is the story message details
SWUS means Stock Way User Story
